# Exam Analytics Studio Pro 🎯

Complete Exam Intelligence Platform with Admit Card Generator

## Features

- 📊 **7 Interactive Tabs**: Dashboard, Demographics, Venues, Search & Profile, Admit Card Generator, Data Viewer, Analytics
- 📄 **Admit Card Generator**: Generate single or bulk admit cards with photos, signatures, and barcodes
- 📸 **Photo & Signature Support**: Automatic matching from folders and ZIP files
- 🔍 **Advanced Search**: Search by name, registration number, or roll number
- 📈 **Analytics**: Comprehensive charts and metrics
- 🔧 **Column Auto-Mapping**: Automatically detects and maps columns
